About precision and offline operation

The permanent starting instant is stored in the source code, not in browser storage. The counter reconstructs elapsed time from that instant whenever the page opens. During temporary network loss, it estimates time using the last accepted synchronization and a monotonic clock. If no trusted estimate exists, it clearly identifies the device clock as a fallback.
