How precise is this, and what happens offline?

The elapsed value is always recomputed as estimated now − fixed start, using exact BigInt nanosecond integers. Nothing is incremented per tick, so throttled tabs, sleep, refreshes and closed browsers lose no time.

“Now” comes from the best source available: (1) a configured time adapter, if any; (2) the HTTP Date header of the server hosting this page (1-second resolution, not an official or atomic source); (3) a monotonic-clock extrapolation from the last good sync while offline; (4) your device clock as a labelled last resort. This site does not yet read Bangladesh’s official BSTI service — no verified browser-accessible interface was established (see README).

Nanosecond digits are the arithmetic representation of an estimate. They are not measured nanosecond accuracy; the uncertainty shown above is the real limit.
